# TheFoster CONVERTER — облачный APK builder

Это начальная тестовая сборка через GitHub Actions. Она собирает APK из статического сайта в папке `site/`.

## Как запустить тест

1. Открой вкладку **Actions** в репозитории.
2. Выбери **Build TheFoster APK**.
3. Нажми **Run workflow**.
4. Укажи название приложения, версию (`1.0` или `1.0.0`) и Package ID.
5. После успешного запуска открой выполненный workflow и скачай APK из раздела **Artifacts**.

## Как добавить свой сайт

Загрузи файлы сайта в папку `site/`. Файл `site/index.html` должен лежать прямо в папке `site`, а не во вложенной папке. Можно добавить CSS, JS, изображения и другие локальные файлы.

## Важные ограничения

- Это прототип для ручного тестирования, а не подключение сайта к автоматическому API.
- Сайт на BeenHost пока не может автоматически отправлять задания в этот репозиторий.
- Собирается **debug APK** для проверки. Для публичного выпуска нужна безопасная подпись release-ключом.
- Внешние страницы/сервисы могут не работать офлайн; веб-приложение должно быть совместимо с WebView.
- Не загружайте секреты, пароли, личные данные или чужие проекты без разрешения.
- Артефакт хранится 3 дня, затем GitHub удалит его автоматически.
